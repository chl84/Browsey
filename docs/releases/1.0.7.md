# Browsey 1.0.7

Planned release date: 2026-11-14. Target: Linux x86_64 (RPM and DEB).

> Release preparation only: this document is not proof of testing or publication.
> Review the changes, platform scope and development/unreleased labels throughout
> README and the docs site before tagging. Fill in validation evidence and remove

## Changes

- Update compatible Rust dependencies: notify 8.2.2, trash 5.3.0, ZIP 9.5.0,
  aes 0.9.4, flate2 1.1.11 and mime 0.3.18. Update frontend and docs-site
  development tooling: Svelte 5.57.3, Vite 7.3.8, Playwright 1.65.0, ESLint
  10.14.0 (docs-site), eslint-plugin-svelte 3.24.1 and typescript-eslint 8.72.2.

- Paste the newest desktop copy when several Browsey instances share the
  clipboard. An instance that had already pasted from another instance kept
  that selection internally and pasted it again after a newer copy elsewhere.
  Each instance now remembers what the desktop clipboard held when it last
  wrote, imported or cleared it, and takes the desktop selection only when it
  has changed since. Its own pending writes, read-back path forms and payloads
  left by failed writes never count as newer. A newer selection that cannot be
  used stops the paste instead of falling back to the older one.

- Release undo backups once Undo/Redo can no longer reach them: when an action
  leaves the 50-action history, when a new action discards Redo, and on normal
  exit. Permanent deletion and overwrites no longer accumulate in
  `undo-sessions` indefinitely. Keep backups with recovery markers or active
  overwrite protection, after a failed Undo/Redo, while a recovery reads them,
  and after a crash. Release unlinks nested symlinks without following them and
  never crosses into another mounted filesystem.

- Update rusqlite to 0.41.1 (bundled SQLite via libsqlite3-sys 0.39.1) to
  resolve RUSTSEC-2026-0459, and rustix to 1.1.6 for RUSTSEC-2026-0486.
  Update webdriverio to 10.2.0 and pin minimatch 10.x consumers to 11.0.8 in
  the frontend and docs-site development tooling for GHSA-g3hv-75wg-m249 and
  GHSA-3g3m-2fjr-6pw4. The low-severity deepmerge advisory has no fix yet.

- Move local items to system trash without copying their entire contents into
  undo storage first. Preserve trees containing symlinks, unreadable children
  and special files. Roll failed or cancelled batches back from the actual
  trash payload, retain blocked restores for retry without overwriting newer
  files, and resolve delayed trash catalogs without a second data copy.

- Preserve progress and cancellation for overlapping operations. Restore the
  older active task when a newer one ends, and scope completion, timers and
  listener cleanup to the originating operation across file and cloud actions.

- Discard stale Recent, Starred, Network and Wastebasket results, errors and
  loading updates after newer navigation. Finish Network setup before publishing
  the location so UI search resets cannot leave its loading indicator stuck.

- Expand desktop Exec placeholders only once, preserving literal percent codes
  in filenames and application names. Honor Linux Terminal=true entries through
  GIO and reap console-launch children after they exit.

- Keep dotfiles hidden and compound archive suffixes intact when generating
  conflict names. Apply acyclic batch-rename chains in dependency order while
  preserving reply order and undo/redo; reject cycles before changing files.

- Update Vitest and its coordinated packages to 4.1.12 to resolve
  GHSA-qxg6-89mg-rqv8 and GHSA-xp26-3454-mjgp in the development test tooling.

- Keep newer navigation and selections when an older path lookup, device
  connection or folder request completes. Cancel queued navigation when changing
  places or using Back/Forward, and reuse connections that are already pending.
  Flush the latest queued bookmark or entered folder once a busy listing ends.

- Preserve reopened creation and rename dialogs when earlier operations finish,
  suppress repeated batch-rename submission, and keep successful changes distinct
  from listing-refresh failures. Avoid returning to a folder or changing the
  selection after the user has navigated elsewhere. Refresh Recent and Starred
  in place after renaming.

- Report listing-refresh errors after completed permanent deletion separately
  from deletion failures, including when deleting items from Wastebasket.

- Measure extraction free space on the actual target filesystem on Unix,
  including mounts omitted from the disk inventory. Preserve the extraction
  reserve, byte and entry limits, and runtime capacity checks.

- Parse additional file-watcher roots as a platform path list instead of
  splitting directory names at path separators. Resolve existing directories
  consistently with the watched path, including spaces and Unicode names.

- Release progress listeners that register after cleanup and ignore obsolete
  cancellation errors. Keep rename/folder and cloud-loading cleanup and delayed
  feedback tied to their operation so an older completion cannot hide a newer
  task, including when opening cloud files.
  Preserve manually chosen recovery destinations during
  delayed startup lookups, and remove temporary clipboard fields on failure.
  Make deferred drag-image cleanup tolerate images that have already detached.

- Explicitly release abandoned-session cleanup locks and released session locks
  even when a duplicate descriptor remains open. Keep active sessions protected.

- Update ZIP to 9.0.4 to resolve RUSTSEC-2026-0367, RUSTSEC-2026-0368 and
  RUSTSEC-2026-0369 concerning extraction permissions and symbolic links.

- Explicitly release temporary backup-session locks after inspection, recovery
  and deletion so inherited file descriptors cannot leave completed operations
  appearing busy. Preserve the lifetime locks protecting active sessions.

- Recognize temp, backup, archive, development/source, configuration, cache,
  fonts, books, games and screenshots folders, shared/share aliases and Norwegian
  names for standard user folders. Generate paired file/folder glyphs from one
  definition, including identical Aa geometry, placement and stroke widths.

- Adapt all Browsey file, folder, sidebar and permission icons to the active
  theme using a shared SVG sprite and semantic palette. Adjust silhouettes and
  details for contrast on normal, selected and drop-target surfaces, including
  high-contrast mode. Use one canonical SVG set with common neutral document
  bodies, angular folders and consistent opaque details. Preserve original
  thumbnail colors; render standalone icon SVGs with the same default palette.

- Restore file-list/grid focus after creating a folder and let Enter on the
  file-list collection open its selected item. Preserve individual row
  activation, modal focus and navigation during asynchronous creation.

- Use the picture icon for PSD files in local and cloud listings. Generate
  thumbnails from embedded JPEG/RGB previews through the existing thumbnail
  cache, scaling and cancellation flow. Read bounded preview data rather than
  entire local PSDs. Fall back to the saved composite for 8/16-bit RGB/grayscale
  files with raw/RLE compression, with bounded pixel allocation and no layer
  rendering. Retain the cloud download size guard and the picture icon when
  neither preview route is supported.

- Follow bounded HTTPS redirect chains when opening OneDrive files, without
  forwarding OAuth credentials to download links. Preserve working-copy version
  checks and log opening failures without exposing signed download URLs.

- Use CLI metadata checks for OneDrive to avoid rclone RC misclassifying folders
  as files and rejecting local-to-cloud copies. Preserve file/missing-path checks,
  cancellation and bounded metadata timeouts.
