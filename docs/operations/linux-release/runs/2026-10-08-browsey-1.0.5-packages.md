flow, including RPM/DEB builds and publication. Follow-up PR work starts after

## Source and packages

Final annotated tag: `v1.0.5`, commit
`45739ae4e3392a67bed6b3de3b17efbc6799a668`.
[Linux Release Bundles](https://github.com/chl84/Browsey/actions/runs/37704633823)
built the production frontend and RPM/DEB on Ubuntu 22.04 using the pinned
Tauri CLI and `--locked`, without native-test features or test IPC.

OpenSSL 3 directly, while its packages declared only WebKitGTK/GTK dependencies.
The final configuration declares `libssl3 | libssl3t64` for DEB and the
`libssl.so.3()(64bit)`/`libcrypto.so.3()(64bit)` requirements for RPM. The workflow
now requires these declarations before uploading artifacts. Only the new,
unpublished candidate tag was corrected, with an explicit old-tag SHA lease
and an absence-of-release check; historical releases/tags/assets were preserved.

## Fresh native DEB checks

The tested executable was extracted from the final downloaded DEB, SHA-256:
`a24af6e4a4fcc0f723c52175051feb97edbb42ea90f1ae6232805ab46bab6c2d`.
The RPM executable has SHA-256:
`cd2cc6edb749ac5ee601afd4d4d4396fb62bcc5f5458dfbf79aa21bb0f037284`.
The RPM was inspected; no separate RPM GUI workflow is claimed.

Native AT-SPI/window-bound actions targeted only the owned DEB process with a
private XDG profile. Its settings and three navigation bookmarks were prepared
as fixtures. The existing rclone 1.75.1 OAuth remote was used in place; tokens
were never printed, copied into fixtures or committed. All remote mutations
were inside one newly generated, ownership-marked Google Drive directory.

| Native case | Independent result |
| --- | --- |
| About | **PASS:** the actual About dialog reported 1.0.5 |
| Duplicate-name listing | **PASS:** two genuine `same.txt` objects appeared as distinct 24-byte and 47-byte rows, including after returning to the cloud folder |
| Selected downloads | **PASS:** each row copied separately into its own empty local destination returned exactly the selected object's 24 or 47 bytes |
| Selected rename | **PASS:** renaming the 47-byte object retained its provider ID and checksum; the 24-byte same-name neighbor retained its original ID/name/checksum |
| Selected trash | **PASS:** normal Delete trashed the renamed selected ID only; the 24-byte neighbor remained active and its ID-based download retained exact bytes |
| Cleanup | **PASS:** the owned process closed normally; the remote ownership marker was checked before trashing only the generated root, and its active entry was absent afterward |

The harness initially searched for the menu as an AT-SPI button. This platform
reports it as a combo box; updating the role selection allowed the genuine
native About action. No file operation was attempted by that failed lookup.
Generated fixture data and private logs remain under `/tmp`. The installed
Browsey was not replaced or restarted by this release task.
